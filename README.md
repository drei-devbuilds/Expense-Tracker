# Expense Tracker

A responsive personal expense tracker built with HTML, CSS, and vanilla JavaScript.

The project allows users to record and manage income and expenses while automatically calculating their current balance.

## Features

- Add income and expenses
- Edit transactions
- Delete transactions
- Search transactions
- Filter by type and category
- Sort transactions
- Automatic income, expense, and balance calculations
- Responsive mobile-first design
- Local storage for persistent data

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
